# ✨ Lumen

Lumen is an AI-powered file onboarding wizard built natively for the Cursor IDE. Instead of scrolling through thousands of lines of unfamiliar code, Lumen illuminates your codebase by breaking down files into logical, structural scopes and walking you through them block-by-block. 

Built with modern glassmorphic UI principles, Lumen acts as an interactive "app-onboarding" guide that moves dynamically with your text editor.

## 🚀 Key Features

*   **🎬 Structural Code Tours:** Dynamically parses language symbols (classes, functions, methods) to highlight active blocks and automatically scrolls the editor to follow your path.
*   **⚡ Live-Streaming AI Analyst:** Leverages Cursor's native LLM capabilities to stream real-time, concise architectural explanations directly into a floating panel as you navigate.
*   **🎛️ Granular Scope Filtering:** Toggle between **Deep Scan** (variables, bindings, and internal expressions) or **Macro Scan** (high-level functions and classes only) to control the depth of your walkthrough.
*   **💬 Contextual "Ask AI" Input:** Got stuck on a complex snippet? Use the inline chat to ask follow-up questions. Lumen instantly bundles the code block, previous explanation, and your prompt for a perfect streamed response.
*   **🎨 Exceptionally Well-Designed UI:** A beautiful, theme-adaptive glassmorphic interface that natively mirrors your Cursor environment layout (supporting light, dark, and custom themes out of the box).
